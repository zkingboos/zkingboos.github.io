## 🧭 Overview & Mission

This repository powers the official engineering portfolio of **José Gabriel (`zkingboos`)**, hosted at [`joseg.xyz`](https://joseg.xyz) (GitHub Pages at `zkingboos.github.io`).

The portfolio is designed with a **cyber-industrial, high-density obsidian & electric cyan aesthetic**, built to showcase real-world systems engineering achievements across 14 years of software development experience (2013 — Present).

Unlike generic template portfolios, this project reflects deep architectural intentionality:
- **Zero-Dependency Core**: Pure modern HTML5, Tailwind CSS, and vanilla ES6+ JavaScript.
- **Physics-Based Momentum Scrolling**: Powered by [Lenis](https://github.com/darkroomengineering/lenis) for fluid, weighted viewport dynamics.
- **Reactive Bilingual i18n**: Instant seamless toggling between Portuguese (`pt`) and English (`en`) with zero layout reflow and persistent user preference.
- **100vw Full-Bleed Cylindrical Tools Slider**: Continuous horizontal marquee of pure vector SVG icons representing core backend and systems technologies (Go, Java, Kotlin, TypeScript, Python, Lua, Docker, Proxmox, Ceph, Kafka, Redis, PostgreSQL, MySQL, Terraform, Tailscale, Linux, Bun, Hono, Git, Kubernetes).
- **Interactive Visualizations**: Interactive draggable microservices topology, live 1,395 contributions heatmap in the Open Source showcase, and an interactive Git DAG commit visualizer.

## ⚡ Quick Start & Development

### 1. Running the Live Preview
The standalone production preview can be served using Python's built-in HTTP server:

```bash
# Serve the preview directory on port 3000
python3 -m http.server 3000 --directory docs/preview/
```

Access the preview at [`http://localhost:3000`](http://localhost:3000).

## 🔒 Core Inviolable Rules

When modifying or expanding this portfolio, all contributors and AI assistants must observe four hard rules:

1. **Zero-Emoji Policy**: Emojis are strictly prohibited anywhere in the codebase (HTML, JS, CSS, and i18n text). Use clean SVGs or monospace ASCII symbols (`->`, `·`, `[ ]`).
2. **Authoritative Palette (Electric Cyan)**: Primary accent is `#09a6d6` (Electric Cyan) on `#06070b` / `#070c16` (Cosmic Obsidian). Purple/violet palettes are strictly rejected.
3. **Hero Layout (Enlarged Avatar on Right)**: The avatar photo is prominently enlarged (`w-56` to `w-72` rounded-3xl) and positioned on the **RIGHT** side of the Hero on desktop, with clean natural styling (no fake CAD crosshairs, no `SYS_ENG`, no blur halo). The left column holds the identity, role title, rotating subtitle, bio, and direct `#contact-hub` CTA.
4. **Pure SVG Icons in Full-Bleed Slider**: The cylindrical marquee slider spans `100vw` (screen edge to screen edge) and contains ONLY vector SVG icons (no text labels) inside frosted capsules.
5. **Open Source Contributions Heatmap**: The 1,395 contributions activity grid is located in Phase 4 (Open Source section), alongside `spigot-mcp` and `UniversalWrapper`.
