**Goal:** Fazer o toggle de idioma (pt/en) traduzir TODOS os textos visíveis do site, incluindo dados (carreira, projetos, open source) e textos hardcoded de componentes que hoje só estão em PT.

**Architecture:** Converter os dados hardcoded (`src/data/career.ts`, `projects.ts`, `openSource.ts`) para o padrão `LocalizedText`/`{ en, pt }` (igual a `src/config/site.ts`), e mover os textos de UI hardcoded dos componentes para o dicionário i18n (`src/locales/pt.json` e `en.json`). Os componentes passam a ler do idioma ativo via `useTranslation`.

**Tech Stack:** React 18, TypeScript, react-i18next.

**Spec:** (auto-contido; segue decisões alinhadas: depoimentos NÃO traduzem — ficam na língua original; dados convertem para padrão `{en,pt}`.)

## Global Constraints

- **Depoimentos (`testimonials.ts`) NÃO são alterados** — permanecem os 11 textos em PT e o 1 em EN (citações na língua original).
- Dados convertem para o padrão `{ en, pt }` (objeto com as duas chaves), idêntico ao `LocalizedText` de `src/config/site.ts`.
- Textos de UI (labels, botões, aria, placeholders) entram no dicionário i18n `pt.json`/`en.json` com a MESMA key em ambos.
- `stack` (tecnologias: "Go · Docker · PostgreSQL") e nomes próprios (empresas, projetos, repositórios, "José Gabriel") NÃO traduzem.
- Helper local: `const lang = i18n.language?.startsWith("pt") ? "pt" : "en";` para ler dos dados `{en,pt}`.
- TDD: cada tarefa termina com teste passando + build ok.
